### Project Limitations

### Current Limitations

### Problem Size

The limitation with the size of the tests and warehouse, is that it only generates 3 possible routes at a time. The warehouse is pretty small, just a 12 by 12 grid.

### Quantum Hardware Limitations

The classical calculations can run very faster because they are performed locally on the user's computer. When connecting and performing to a real quantum computer, the program takes more time to connect before executing the task, and even more time to process the task.

### Simplified Warehouse Environment

This demonstration is a very simple version of a simulated warehouse. In a real warehouse, their would be more contraints like the robot's energy level and obstacles having diffrent shapes other than just a square.

### Future Improvements

There are many improvements that can be added to this project including:

-Larger warehouse size
-More real life contraints like battery level
-More obstacle shapes

### Conclusion

The simulation for a robot in a warehouse performs better when using classical calculations rather than quantum computing because of slower calculation times, most likely due to slow connectivity time.
